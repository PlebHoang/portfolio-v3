## 5. Projects & Builds

### Feature 1: AI-Integrated Morning Assistant
* **Period**: Jan 2026
* **Role**: System Architecture & Automation
* **Badge**: 60 min → 3 min
* **Context**: I was losing nearly an hour every week manually organizing calendar events, Notion tasks, and scattered quick notes.
* **Build**: Wrote and containerized a Python workflow on Docker using the Gemini API and Discord webhooks. It ingests messy unstructured inputs, classifies priority, and syncs the schedule automatically.
* **Result**: Reduced weekly schedule planning from 60 minutes to 2-3 minutes.
* **Stack**: Python, Docker, Gemini API, Bash, Discord Webhooks

### Feature 2: Gemini × Makers Odyssey Hackathon
* **Period**: Dec 2025
* **Role**: Physical Prototyping & Mesh Comms
* **Badge**: 3rd Place Winner
* **Context**: A 48-hour challenge to design and assemble a functional Mars exploration rover capable of offline communication.
* **Build**: Designed an adaptable wheel chassis in Fusion 360, 3D-printed parts on-site, and programmed ESP-to-ESP wireless mesh telemetry in Arduino so rover units could exchange sensor data without internet or base stations.
* **Result**: Delivered a working physical rover within the 48-hour limit, earning 3rd place overall.
* **Stack**: Fusion 360, 3D Printing, Arduino, ESP Mesh
